# Roadmap (ideas, not commitments)

- Multi-vault routing or per-vault Telegram bots.
- Richer allowlists (multiple users with different templates or target folders).
- Custom append templates (Mustache or similar) and optional heading targets.
- Media beyond voice/audio (photos, files) with vault paths.
- Retry queue / deduplication for failed writes or ASR.
- Cloud ASR or LLM summarization as optional backends.
- Mobile support (would require revisiting `isDesktopOnly` and networking constraints).
- Automated tests for diary cutoff and ASR client wiring.
